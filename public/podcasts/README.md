# Podcast Audio Files

Place your podcast audio files in this directory. They will be publicly accessible at:
`/podcasts/[filename]`

## Supported Formats:
- MP3 (recommended)
- M4A
- WAV
- OGG

## Naming Convention:
Suggested format: `episode-[number]-[title-slug].mp3`

Examples:
- `episode-001-ai-search-future-of-seo.mp3`
- `episode-002-geo-blocking-deep-dive.mp3`
- `daily-dive-2025-06-20-custom-vs-saas.mp3`

## Access URL:
Once uploaded, files will be available at:
`https://yourdomain.com/podcasts/[filename]`
